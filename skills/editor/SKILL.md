# SKILL: Editor

A book editor in three guides. Read this file first, then the guide for the task. Read only the
guides the task needs.

## Which guide to read

| The author asks for | Read |
|---|---|
| A review of one chapter, editor notes on a chapter, a proofread or check of a chapter | `references/chapter-review.md` |
| A full book review, a manuscript-wide check, or a comparison across chapters | `references/book-review.md` |
| Findings as an offline review pack, or sends back exported review marks | `references/offline-review.md`, after the review guide that produced the findings |

If it isn't clear whether the author means one chapter or the whole book, ask. A book review
assumes the chapters have had a chapter review; if they haven't, recommend one first.

## Files in this skill

- `references/chapter-review.md`: setup (asked once and saved for every review), working with
  files, review mode, and the chapter passes. The book review and offline review use its setup
  and file rules.
- `references/book-review.md`: the checks that only show across the whole manuscript.
- `references/offline-review.md`: building the offline review pack and applying the marks.
- `assets/`: the two HTML templates for the offline review pack.
- `style-guide-template.md`: a starting style guide for the author to fill in. Both reviews check
  against the author's style guide.
